# SkillSeek – Student Skills Marketplace

 **Connecting student talent with real opportunities.**

SkillSeek is a web-based platform that connects students with employers for freelance, short-term, and project-based opportunities.

## ✨ Features

### Students

* Create and manage profiles
* Showcase skills, education, and experience
* Browse and save jobs
* Apply for opportunities
* Track applications
* Communicate with employers

### Employers

* Create company profiles
* Post and manage jobs
* Review applications
* Communicate with students

### Platform

* Authentication and role-based access
* Job categories
* Messaging and notifications
* Reviews and ratings
* MySQL database integration

## 🚀 Setup

### Requirements

* PHP
* MySQL
* XAMPP
* Apache
* phpMyAdmin

### Installation

```bash
git clone https://github.com/JHUB-AFRICA/skill-seek.git
```

1. Move the project to `htdocs`.
2. Start **Apache** and **MySQL** in XAMPP.
3. Create a database named `skillseek` in phpMyAdmin.
4. Import `database.sql`.
5. Configure `config/database.php`.
6. Open:

```text
http://localhost/SkillSeek/
```

## 🗄️ Database

SkillSeek uses MySQL to manage:

* Users and profiles
* Jobs and categories
* Applications
* Messages
* Notifications
* Reviews
* Payments

The database structure is provided in `database.sql`.

## 🔄 CI/CD

SkillSeek uses **GitHub Actions** for continuous integration and deployment.

The workflow is maintained in:

```text
.github/workflows/
```
